# thekingssurveyor.com

One-page official site for The King's Surveyor. Plain HTML and CSS, hosted on GitHub Pages.

- `index.html`, `style.css`: the page.
- `assets/`: web-sized images built from the press kit (D:\Devgit\TheKingsSurveyor\PressKit). Rebuild from there, never edit in place.
- `fonts/`: Mountain King (CC BY 4.0, Michael W. Moss), credited in the footer.
- `CNAME`: custom domain for GitHub Pages. DNS at IONOS: four A records on the apex to GitHub's Pages IPs, one CNAME for www to dragonborn89.github.io.
- `robots.txt`, `sitemap.xml`: for Google Search Console.

All copy is the Steam page and press fact sheet text, verbatim. Change it there first, then here.
